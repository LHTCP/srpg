# SRPG 후속 과제 (백로그)

구현 우선순위는 플레이테스트 결과에 따라 조정한다.

---

## 높음 — 다음 작업 대상

| 항목 | 내용 |
|------|------|
| **턴 넘기기 이중 클릭 방지** | `_endTurnLock` 코루틴(1프레임 쿨다운) 구현. "플레이어 턴 종료" 버튼 클릭 직후 동일 버튼 재클릭 차단. |

---

## 중간 — 프로토타입 완성도

| 항목 | 내용 |
|------|------|
| **로그 ScrollRect** | 현재 로그는 최근 22줄만 표시(Truncate). ScrollRect + Content 방식으로 전체 열람. |
| **TMP(TextMeshPro) 전환** | 한글·영문 가독성 향상. Legacy Text 폰트의 한계(스무딩·크기) 해결. |

---

## 낮음 — 이후

| 항목 | 내용 |
|------|------|
| **AI 스텁** | 무작위 합법 수 AI(이동·공격 랜덤). 레벨 밸런스 테스트용. |
| **2인 원격 세션** | 핫시트 검증 후. 액션 커맨드 스트림 기반 동기화. [SRPG_FUTURE_NETWORK.md](SRPG_FUTURE_NETWORK.md) 참고. |
| **맵 에디터 개선** | 현재 DevTools는 JSON 저장/로드만. 인게임 타일·유닛 배치 인터페이스 추가. |
| **스킬 시스템 확장** | 현재 `heart_spike`, `fh_bless_ally` 스텁만. 버프/디버프, 범위 효과, FH 조작 등 확장. |
| **레거시 체스 정리** | `Assets/Scripts/Chess/`는 현재 참고용. SRPG 안정화 후 제거 여부 결정. |
| **`Resources/SrpMaps/` 배포 맵** | 빌드 배포 시 읽기 전용 맵 번들링 경로 정리. |
