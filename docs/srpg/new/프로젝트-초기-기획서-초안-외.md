# 프로젝트 초기 기획서 초안 외 (PDF 변환본)

원본 파일: `docs/srpg/new/프로젝트 초기 기획서 초안 외.pdf`  
변환 시각: 2026-04-25

## 1. 변환 상태

- 현재 저장소 환경에서 PDF 본문은 텍스트 레이어가 아닌 압축 스트림 중심으로 확인되었다.
- 자동 추출 결과가 대부분 바이너리 스트림으로 출력되어, 문장 단위 OCR 텍스트 복원이 불가했다.
- 따라서 본 문서는 **원문 변환 메타 + 활용용 정규화 규칙**을 우선 제공한다.

## 2. 확인된 원문 특성

- 파일은 유효한 PDF 구조(`%PDF-1.7`)를 가진다.
- 여러 `FlateDecode` 스트림과 CID 폰트 매핑이 포함되어 있다.
- 일반 텍스트 문단이 직접 노출되지 않아 line 기반 파싱으로는 읽기 어렵다.

## 3. 표준 용어 정규화 규칙

PDF 후속 OCR/수기 정리 시 아래 표준 용어를 사용한다.

| 비표준/혼용 가능 표기 | 표준 표기 |
| --- | --- |
| 반응포인트, Reaction Point | RP |
| 행동포인트, Action Point | AP |
| 자세게이지, 균형게이지 | PG |
| 가드, 방어행동 | Guard |
| 회피행동 | Dodge |
| 반격/카운터 | Parry(패링) |
| 경계사격, 대기사격 | ReactionShot / 오버워치 반응사격 |
| 공격형/방어형 태세 | 공격 태세 / 수비 태세 |

## 4. 후속 OCR 처리 가이드

1. 원본 PDF를 OCR 가능한 도구로 텍스트 레이어화한다.
2. OCR 산출 텍스트를 본 문서 하위에 `## OCR 본문` 섹션으로 추가한다.
3. 문장마다 `RQ-*`/`TBD-*` 태그를 붙여 `SRPG_NEW_DIALOG_POLICY_LOCK.md`와 교차 검증한다.
4. 모순 항목은 `SRPG_BACKLOG.md`의 문서 작업 항목으로 먼저 등록한다.

## 5. 현재 활용 지침

- 전투 규칙 확정은 본 PDF가 아니라 `06~10 대화 원본`을 우선 기준으로 사용한다.
- PDF는 보강 근거 자료로만 사용한다.
- 본 PDF와 상충 시:
  - 1순위: `SRPG_전투규칙_기준서_v2.md`
  - 2순위: `SRPG_NEW_DIALOG_POLICY_LOCK.md`
  - 3순위: OCR 정리본
