## 작업 원칙

1. 하위 문서(GDD/TDD/마스터플랜/백로그)는 위 `RQ-*`를 기준으로 서술을 통일한다.
2. `TBD-*`는 미정으로 남기되, 구현 문서에 확정처럼 쓰지 않는다.
3. 코드 2차 착수 문서는 모든 작업 항목을 `RQ-*` 또는 `TBD-*`에 연결한다.
