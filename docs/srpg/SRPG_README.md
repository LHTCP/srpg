# SRPG 프로토타입 실행 방법

## 씬에 붙이기

1. 빈 GameObject를 만들고 `SrpGameController` 컴포넌트를 추가한다.
2. **Initial Map**을 비워 두면 **Start Preset** 인스펙터 값에 따라 내장 맵이 로드된다.
3. (선택) `SrpDevTools` 컴포넌트를 추가하고 `Game` 필드에 컨트롤러를 연결한다.
4. **Main Camera**는 `Frame Camera On Start`가 켜져 있으면 보드 크기에 맞춰 **직교 탑다운**으로 자동 정렬된다.

> **주의**: `SrpMapFileV1`은 인스펙터에서 null이 아닌 빈 객체로 직렬화된다.  
> Initial Map 필드를 비워 두려면 인스펙터에서 참조를 지정하지 않으면 된다.  
> `placements`가 비어 있으면 자동으로 `Start Preset`의 내장 맵을 사용한다.

## 화면 구성

```
┌──[LEFT 420px]──┬──────────────────────┬──[RIGHT 420px]──┐
│ 플레이어·맵 정보 │                      │ [로그 숨기기]    │
│ 상태 메시지     │   보드(화면 중앙)     │ ...로그 내역...  │
│ 선택 유닛 스탯  │                      │                 │
│ ─────────────  │                      │                 │
│ [유닛 완료]     │                      │                 │
│ [플레이어 턴 종료│                      │                 │
│ [되감기]        │                      │                 │
└────────────────┴──────────────────────┴─────────────────┘
```

- **LeftPanel**: 턴/맵 정보, 상태 메시지, 선택 유닛 스탯, 액션 버튼.
- **RightPanel**: 로그 토글 버튼(항상 표시) + 로그 텍스트 영역.
- 패널 폭: 인스펙터 `Left Panel Width` / `Right Panel Width` (기본 420).

## 내장 맵 프리셋

| 프리셋 | 크기 | 특징 |
|--------|------|------|
| **TinyDuel** | 6×4 | 기사 1vs1, 장애물 없음 — 입력·이동 검증 |
| **Corridor** | 8×10 | 중앙 2칸 장애물 띠, 통로 y=5 — ZOC·우회 |
| **Skirmish** | 10×8 | 다수 유닛·보스 브루트(2칸 풋프린트) 포함 |

## 조작

### 턴 흐름

1. 현재 플레이어의 유닛이 있는 **타일을 클릭**해 활성화.
2. 녹색 칸(이동 가능) 클릭 → 이동. 잔여 이동력 내에서 반복 가능.
3. 붉은 칸(공격 가능 적) 클릭 → 공격(1회). 공격 즉시 해당 유닛 활성화 종료.
4. **[유닛 완료]** 버튼 → 공격 없이 해당 유닛 활성화 종료.
5. 다른 유닛을 선택하려면 현재 유닛을 먼저 완료해야 한다.
6. 모든 유닛을 운용한 뒤 **[플레이어 턴 종료]** 클릭 → 상대방 턴.

### 버튼

| 버튼 | 활성 조건 | 동작 |
|------|-----------|------|
| **유닛 완료** | UnitActive 상태 | 현재 유닛 행동 종료, Idle 복귀 |
| **플레이어 턴 종료** | Idle 상태 | 다음 플레이어로 턴 이동 |
| **되감기** | 항상 | 직전 액션 취소(스냅샷 복원) |
| **로그 숨기기/보기** | 항상 | 우측 로그 패널 텍스트 토글 |

## 유닛 표시

| 색상 | 의미 |
|------|------|
| 파란 원판 | 플레이어 0 유닛 |
| 빨간 원판 | 플레이어 1 유닛 |
| 노란 보정 | 보스 태그 |
| 크기 대형 | Large 태그(2칸 이상 점유) |

## 개발자 도구 (에디터·Development Build)

- **F3** 키: 화면 오른쪽 상단에 패널 표시/숨김.
- 기능: 파일명 입력 → JSON 저장 / 불러와 즉시 적용 / 씬 재시작.
- 저장 경로: `Application.persistentDataPath/SrpMaps/`.
- 릴리스 빌드에서 `Debug.isDebugBuild`가 아니면 비표시.

## 로비 씬 구성

### 씬 추가 순서

1. **`SrpgLobby` 씬** 생성 → 빈 GameObject에 `SrpLobbyController` 컴포넌트 추가.
2. **기존 전투 씬** 이름을 `SrpgBattle`로 변경.
3. **Build Settings** → 두 씬을 모두 등록 (Lobby 먼저).

### 로비 화면

```
┌────────────────────────────────────────────┐
│         SRPG 프로토타입                     │
│      전투 시작 전 맵을 선택하세요            │
│  ──────────────────────────────────────    │
│               맵 선택                      │
│  [TinyDuel]   [Corridor]   [Skirmish ★]   │
│  ──────────────────────────────────────    │
│      JSON 맵 로드 (선택사항)                │
│  [파일명______________________] [불러오기] │
│  ──────────────────────────────────────    │
│             [ ⚔ 전투 시작 ]               │
└────────────────────────────────────────────┘
```

- 프리셋 버튼 클릭 시 강조색으로 선택 표시.
- JSON 불러오기 성공 시 해당 맵으로 전투 시작 (프리셋 무시).
- JSON 저장 경로: `Application.persistentDataPath/SrpMaps/`.

### 전투 씬 HUD 추가 버튼

| 버튼 | 동작 |
|------|------|
| **◀ 로비로 돌아가기** | 로비 씬(`SrpgLobby`)으로 씬 전환 |
