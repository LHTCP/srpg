# 향후: 네트워크·AI·다인 슬롯 (기획 메모만)

이 문서는 **구현 범위 밖** 설계 메모다. 프로토타입은 핫시트만 지원한다.

## 목표

- 본편은 **1인 + AI**를 전제로 할 수 있으나, 레벨 검증을 위해 **원격 2인** 세션이 필요해질 수 있다.
- 한 맵에 **최대 6 플레이어 슬롯**; 모두 같은 필드에 있지는 않을 수 있음(맵 메타데이터로 정의).
- **아군·중립** 유닛은 연결된 플레이어가 **공동으로 조작**할 수 있게 하는 것이 이상적이다.

## 데이터 모델 확장 아이디어

- `playerOrder[]`: 턴 순서.
- 각 플레이어에 `controllerKind`: `HumanLocal`, `HumanNetwork`, `AI`, `SharedHuman`.
- `sharedControlGroupId`: 같은 그룹 ID인 플레이어는 같은 입력 풀(또는 동시 조작 허용)로 묶을 수 있음.
- 네트워크 동기화 시 **액션 로그 스트림**(이미 구현된 로그·되감기 구조)을 권위 있는 상태로 두고, 클라이언트는 동일 시드·동일 커맨드 적용으로 재현.

## 단계 제안

1. 핫시트 프로토타입 안정화 및 맵 파이프라인 고정.
2. 로컬 **AI 스텁**(무작위 합법 수)으로 규칙 검증.
3. **세션 호스트/게스트** 1대1 연결(전송 내용은 액션 커맨드 + 시드).
4. 공동 조작·6인·관전자 — 후순위.

## 프로덕션에서 에디터 잠금

- 배포 빌드에서는 `SrpDevTools` 및 맵 편집 진입이 비활성(에디터·DEVELOPMENT_BUILD만 허용하는 현재 방침과 동일 계열).
- 콘텐츠는 빌드에 포함된 읽기 전용 맵만 로드.
