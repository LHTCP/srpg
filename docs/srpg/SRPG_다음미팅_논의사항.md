# SRPG v1 의사결정 메모

상태: 과거 기준 참고 문서. 현재 구현 우선순위와 스프린트 계획은 `SRPG_BACKLOG.md`와 `SRPG_PHASE2_CODE_BACKLOG.md`를 따른다.

## 우선순위 A (이번 스프린트 착수 전 확정)

1. **총기 조건부 살상력 수치**
   - 근거리/노엄폐/측후방/조준/PG 붕괴의 배율과 중첩 방식
2. **AP 2 + RP 1 세부 규칙**
   - 미사용 AP/RP 이월 여부
   - 턴 시작/종료 시 초기화 시점
3. **태세 전환 비용**
   - 무비용 즉시 전환 vs AP 소모 전환
4. **교전상태 강제 이탈 규칙**
   - 이탈 시점, 기회공격 횟수, 후방 이탈 예외

## 우선순위 B (M2 완료 전 확정)

1. **패링 자동 발동 조건**
   - 무기 타입, 태세, 방향(정면 한정 여부), RP 소모 방식
2. **경계태세 상세 규칙**
   - AP 1 소모 고정 여부
   - 적 턴에서 발동 횟수 제한
3. **LOS/엄폐 모델**
   - 하프커버/풀커버 단계화 여부
   - 판정 단위(타일 단위 vs 유닛 중심점)
4. **회전 비용**
   - 방향 전환이 이동에 포함되는지 별도 행동인지

## 우선순위 C (M3~M4 진입 전 확정)

1. **마법 역할 경계**
   - 직접 피해 허용 상한
   - 위치 강제 이동, 사선 차단, 구조 스킬 비율
2. **특수 적 설계**
   - 장갑병/메카/보스의 약점 방식(부위 파괴 vs 조건부 붕괴)
3. **힐러 철학 구체화**
   - 응급처치/보호/PG 회복/상태 해제의 허용 범위
4. **수치 스케일 잠금**
   - 인간형 기준 HP/PG, 역할군별 편차 범위
