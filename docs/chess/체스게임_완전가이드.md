## 🎮 Unity 기본 개념 (초보자용)

### GameObject란?
```
Unity에서 모든 것은 GameObject입니다.
- 체스 말 = GameObject
- 체스 타일 = GameObject  
- 카메라도 GameObject
- 심지어 빈 오브젝트도 GameObject
```

### Component란?
```
GameObject에 기능을 추가하는 것이 Component입니다.
- Renderer Component = 화면에 보이게 함
- Collider Component = 충돌 감지
- 우리가 만든 Script도 Component!
```

### Transform이란?
```
모든 GameObject는 Transform을 가집니다.
- Position (위치): (x, y, z)
- Rotation (회전): 각도
- Scale (크기): 크기 배율
```

### Prefab이란?
```
재사용 가능한 GameObject 템플릿입니다.
- 체스 말 프리팹을 만들면
- 같은 말을 여러 개 쉽게 만들 수 있음
```

## 🔧 C# 기본 개념 (초보자용)

### 클래스 (Class)
```csharp
public class ChessPiece : MonoBehaviour
{
    // 이것은 '체스 말' 클래스입니다
    // 모든 체스 말의 공통 기능을 정의
}
```

### 상속 (Inheritance)
```csharp
public class Pawn : ChessPiece
{
    // Pawn은 ChessPiece를 상속받음
    // ChessPiece의 모든 기능 + 폰만의 특별한 기능
}
```

### 추상 클래스 (Abstract Class)
```csharp
public abstract class ChessPiece
{
    // abstract = 직접 사용 불가, 상속만 가능
    // 공통 기능은 여기에, 개별 기능은 자식 클래스에서
}
```

### 배열과 리스트
```csharp
// 배열 (크기 고정)
ChessTile[,] tiles = new ChessTile[8, 8]; // 8x8 2차원 배열

// 리스트 (크기 가변)
List<ChessPiece> pieces = new List<ChessPiece>(); // 동적 크기
```

## 📁 파일 구조 설명

```
Assets/Scripts/Chess/
├── ChessBoard.cs          🏁 메인 보드 관리

├── ChessPiece.cs          ♟️ 모든 말의 기본 클래스
├── ChessGameManager.cs    🎮 게임 전체 관리
└── Pieces/
    ├── Pawn.cs           ♟️ 폰
    ├── Rook.cs           🏰 룩  
    ├── Knight.cs         🐎 나이트
    ├── Bishop.cs         ⛪ 비숍
    ├── Queen.cs          👑 퀸
    └── King.cs           👑 킹
```

### 각 파일의 역할

**🏁 ChessBoard.cs**
- 8x8 체스판 생성
- 모든 체스 말의 초기 배치
- 보드 전체 상태 관리

**🟫 ChessTile.cs**  
- 체스판의 각 칸 관리
- 타일 색상 (흰색/검은색)
- 현재 위치한 말 추적
- 마우스 클릭 감지

**♟️ ChessPiece.cs**
- 모든 체스 말의 공통 기능
- 이동, 위치 관리
- 각 말별 고유 기능은 상속받는 클래스에서 구현

**🎮 ChessGameManager.cs**
- 게임의 두뇌 역할
- 턴 관리 (흰색/검은색)
- 말 선택 및 이동 처리
- 게임 상태 확인

## ⚙️ Unity에서 설정하기

### 1단계: 기본 설정

1. **체스보드 오브젝트 생성**
   ```
   Hierarchy 우클릭 → Create Empty
   이름: "ChessBoard" 
   Inspector에서 ChessBoard.cs 스크립트 추가
   ```

2. **게임매니저 오브젝트 생성**  
   ```
   Hierarchy 우클릭 → Create Empty
   이름: "ChessGameManager"
   Inspector에서 ChessGameManager.cs 스크립트 추가
   ```

3. **카메라 위치 조정**
   ```
   Main Camera 선택
   Position: (0, 10, -5)  
   Rotation: (45, 0, 0)
   → 체스판을 위에서 보는 각도
   ```

### 2단계: 컴포넌트 연결

**ChessGameManager 설정:**
- Inspector에서 "Chess Board" 필드에
- Hierarchy의 ChessBoard 오브젝트를 드래그

### 3단계: 게임 실행  
- **Play 버튼 클릭!**
- 자동으로 체스판과 말들이 생성됨

## 📖 스크립트 상세 설명

### 🏁 ChessBoard.cs 핵심 기능

```csharp
void CreateBoard()
{
    // 8x8 반복문으로 64개 타일 생성
    for (int x = 0; x < 8; x++)
    {
        for (int y = 0; y < 8; y++)
        {
            // 타일 하나씩 만들어서 배치
        }
    }
}
```

**무엇을 하나요?**
- 이중 반복문으로 8x8 격자 생성
- 각 위치에 타일 오브젝트 생성  
- 체스판 패턴으로 색상 설정

```csharp
void SetupPieces()
{
    // 폰은 2번째, 7번째 줄에 배치
    for (int x = 0; x < 8; x++)
    {
        CreatePiece(PieceType.Pawn, true, x, 1);   // 백 폰
        CreatePiece(PieceType.Pawn, false, x, 6);  // 흑 폰  
    }
}
```

**무엇을 하나요?**
- 체스 말들을 정확한 시작 위치에 배치
- 백: 0,1번 줄 / 흑: 6,7번 줄

### 🟫 ChessTile.cs 핵심 기능

```csharp  
void OnMouseDown()
{
    ChessGameManager.Instance?.OnTileClicked(this);
}
```

**무엇을 하나요?**
- 타일을 클릭하면 게임매니저에게 알림
- `?.` = null-safe 연산자 (매니저가 없어도 에러 안남)

### ♟️ ChessPiece.cs 핵심 기능

```csharp
public abstract List<ChessTile> GetPossibleMoves();
```

**무엇을 하나요?**
- `abstract` = 자식 클래스에서 반드시 구현해야 함
- 각 말별로 다른 이동 규칙을 강제함

```csharp
protected List<ChessTile> GetStraightMoves(int maxDistance = 8)
{
    // 직선 이동 (룩, 퀸이 사용)
}

protected List<ChessTile> GetDiagonalMoves(int maxDistance = 8)  
{
    // 대각선 이동 (비숍, 퀸이 사용)
}
```

**무엇을 하나요?**
- 공통적인 이동 패턴을 미리 구현
- `protected` = 상속받은 클래스에서만 사용 가능

## 🎮 게임 플레이 방법

### 기본 조작
1. **말 선택**: 현재 턴의 말을 클릭
2. **이동 확인**: 가능한 위치가 초록색으로 표시
3. **이동 실행**: 원하는 위치 클릭  
4. **턴 변경**: 자동으로 상대편 턴

### 시각적 피드백
- 🟡 **노란색**: 선택된 말의 위치
- 🟢 **초록색**: 이동 가능한 위치
- ⚪ **흰색**: 흰색 타일
- 🟫 **갈색**: 검은색 타일

## 🔧 문제 해결

### 자주 발생하는 문제들

**Q: 체스말과 타일 위치가 안 맞아요**
```
A: 이미 수정된 코드에서는 해결됨
   - ChessTile.SetPiece()에서 타일 위치 기준으로 말 배치
   - transform.position을 사용해서 정확한 위치 계산
```

**Q: 스크립트를 추가할 수 없어요**
```  
A: 컴파일 에러 확인
   1. Unity Console 열기 (Window → General → Console)
   2. 빨간색 에러 메시지 확인
   3. Assets → Refresh (Ctrl+R) 시도
   4. Unity 재시작
```

**Q: 말이 클릭되지 않아요**
```
A: Collider 확인
   1. 말 오브젝트에 Collider가 있는지 확인
   2. CreatePrimitive로 만든 오브젝트는 자동으로 Collider가 생성됨
   3. 카메라에서 Raycast가 닿을 수 있는 위치인지 확인
```

**Q: 게임매니저가 연결되지 않아요**
```
A: 참조 연결 확인  
   1. ChessGameManager 오브젝트의 Inspector 확인
   2. "Chess Board" 필드에 ChessBoard 오브젝트 할당
   3. 싱글톤 패턴으로 자동 연결되어야 함
```

## 📝 Unity 용어 사전

**GameObject**: Unity의 모든 오브젝트의 기본 단위
**Component**: GameObject에 기능을 추가하는 요소  
**Transform**: 위치, 회전, 크기 정보
**Prefab**: 재사용 가능한 GameObject 템플릿
**Inspector**: 선택된 오브젝트의 정보를 보여주는 창
**Hierarchy**: 씬의 모든 GameObject를 보여주는 창
**Scene**: 게임의 한 장면 (메뉴, 게임플레이 등)
**Raycast**: 3D 공간에서 광선을 쏴서 충돌 감지
